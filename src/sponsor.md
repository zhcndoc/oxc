# 🌟 成为 Oxc 赞助商

## 🤝 如何赞助

您可以通过 [OpenCollective](https://opencollective.com/oxc) 赞助我们。

我们的 [GitHub Sponsors](https://github.com/sponsors/oxc-project) 页面在设置过程中遇到了一个错误，目前仍在等待处理，因此 OpenCollective 暂时是唯一的选择。

## 💚 为什么要赞助？

赞助让我们能够持续改进 JavaScript 和 Rust 生态系统，同时避免过度劳累。

我们在 OpenCollective 上收到的所有赞助款，都会支付给不属于 [VoidZero](https://voidzero.dev) 的核心团队成员。

作为赞助者，你的头像会显示在所有 [oxc-project 仓库](https://github.com/oxc-project) 以及本网站的[首页](/)上。

如果我们的工作改善了你的开发体验、CI 流水线、构建速度或学习过程，请考虑赞助我们。这份支持比你想象的更有帮助，也让我们保持动力。
